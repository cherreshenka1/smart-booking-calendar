# Smart Booking Calendar

Сервис онлайн-записи с календарём, выбором услуги, тайм-слотами, подтверждением бронирования и сохранением записей.

## Живая версия

[https://cherreshenka1.github.io/smart-booking-calendar/](https://cherreshenka1.github.io/smart-booking-calendar/)

## Возможности

- выбор услуги
- календарь по ближайшим датам
- свободные и занятые слоты
- форма клиента
- подтверждение бронирования
- список ближайших записей
- фильтры по услуге и дате
- сохранение в `localStorage`

## Запуск

```bash
npm install
npm run dev
```

## Деплой

```bash
npm run deploy
```

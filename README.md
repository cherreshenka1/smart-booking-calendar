# smart-booking-calendar

Самостоятельный интерактивный проект: выберите время встречи.

[Открыть сайт](https://cherreshenka1.github.io/smart-booking-calendar/) · [Кейс](https://cherreshenka1.github.io/portfolio/projects/smart-booking-calendar/) · [Промпт и критерии доработки](https://github.com/cherreshenka1/portfolio/blob/main/prompts/smart-booking-calendar.md)

## Сценарий

Создать учебную запись, убедиться, что время занято, и отменить её.

Свободное время зависит от длительности услуги и других записей специалиста. До подтверждения видны дата, слот и часовой пояс. Запись можно отменить.

## Границы

Проверка сценария записи в браузере; встреча не назначается внешнему специалисту.

## Проверить вручную

1. Выбрать услугу.
2. Выбрать дату и время.
3. Создать демо-запись.
4. Отменить запись.

Проверены основной сценарий и адаптивная вёрстка при ширине 390 и 1280 px. Это проверка прототипа, а не сертификация готовности к промышленной эксплуатации.

## Разработка

React 18, Vite 5. Node.js 20+.

```sh
npm ci
npm run dev
npm run build
```

`npm run deploy` собирает приложение и публикует `dist` в ветку `gh-pages` текущего репозитория.
